# 功能与适配说明

[返回 README](../README.md) · [配置参考](CONFIGURATION.md) · [安全部署](SECURITY.md)

## 部署后能否直接使用

可以。完成一次性安装码引导、创建管理员后，就能在后台维护提问箱、歌单、画廊、名单、舰礼、地址收集和电子礼物等基础业务。站名、头像、品牌／模块图标、配色、背景、表情和备案页脚都有后台入口，不需要为每位主播修改源码。

新站没有主播内容、用户地址、名单或礼物文件。需自行添加内容、发布礼物和收集批次，选择是否开放舰礼目录及粉丝账户。粉丝完成注册只证明账号归属，领取范围仍由名单确定。修改头像或主题不会替换业务数据。

“无需开发”仍以完成部署配置为前提：服务需要持久化数据，公网访问需要域名、HTTPS和正确的可信代理。应用默认提供限速、临时封禁和安全记录；覆盖、预算与恢复方式见[安全部署](SECURITY.md)。

| 画廊与粉丝投稿 | 画廊管理 | 上传自己的作品素材，并审核粉丝投稿 |
| 舰礼与电子礼物 | 大航海回馈、电子礼物 | 设置礼物内容、自己的附件，以及按业务需要导入的名单 |
| 地址批次、地址簿、常用地址／托管、发货与运单 | 大航海回馈相关页面 | 配置领取范围、发布批次；主播托管须先取得本人确认 |
| 粉丝账户、签名验证与找回密码 | 系统设置控制账户开放；粉丝在前台操作 | 服务器能读取 B 站公开签名；不需官方 OAuth 应用，也不需专门配置验证账号 Cookie |
| B 站上舰记录导入、昵称头像同步和私信队列 | 名单与通知页面、系统设置 | 主播自己的扫码会话、账号权限和测试收件 UID；受 B 站风控与接口变化影响 |
| AI 辅助审核 | 系统设置 → AI 辅助审核 | 自己的兼容服务、模型和 API Key，可能产生上游费用 |
| OSS 文件存储 | 系统设置 → 部署与集成 | 私有 Bucket 和适当权限的凭据；默认本地存储无需购买 OSS |
| 应用防护与安全记录 | 默认启用；站点所有者在「安全」查看及管理封禁 | 持久化本地状态目录，核对可信代理；不需要先安装 Fail2ban。服务器与网络层保护仍独立维护 |

舰礼目录与粉丝账户有独立开关，草稿也不会自动发布。某入口未显示时，先核对开放设置与发布状态，不必因此改代码。

## 桌宠

现有功能是浏览器中的 **VRM 3D 模型加载与交互**。后台已提供以下配置：

- 「主题管理 → 鼠标与桌宠」：显示开关、模型地址、桌宠名称与默认展开状态。

**没有模型上传、模型制作、动作编辑、服装管理或 Live2D 导入入口，仓库也不附带角色模型。**

若已有适配现有渲染器的标准 VRM，一般可以按以下方式启用，无需改业务代码：

1. 确认模型允许网站展示和相应分发方式。
2. 将文件放在自己管理的公开静态文件位置，或支持浏览器跨域读取的 HTTPS 存储地址。站内路径应指向实际静态文件，不要把私有 `data/` 整体公开，也不要把需要登录鉴权的附件下载地址当作公开模型地址。
3. 在「主题管理」填写可访问的模型地址、名称，开启显示并保存。
4. 在桌面端检查模型是否加载、姿态和表情是否正常。手机端不加载模型。

模型的骨骼、朝向、材质或表情不兼容时，需要调整素材或适配渲染器。专属动作、换装、新交互或 2D／Live2D 桌宠也需要单独开发；填入文件地址不能完成这些工作。具体模型需在目标站点验收，未对任意第三方模型做兼容性保证。

## 自定义鼠标

发行版只有系统指针。在后台「主题管理 → 鼠标与桌宠」选择已有套装并开启自定义鼠标；**这里没有素材上传或套装编辑功能**。

添加自定义套装需要制作资源并修改发行内容：

1. 制作有权使用的鼠标精灵图，准备 JSON manifest，包含 `cursors` 和 `cssBindings`。各指针需描述精灵图路径、帧数、帧宽高、帧间隔与热点坐标。
2. 将前后台需要的文件放入各自静态资源目录，使 manifest 和精灵图 URL 都能访问；核对路径在前台与 `/admin/` 下均有效。
3. 在 `internal/appearance/cursor-themes.json` 登记套装的 `id`、`name` 和 `manifest`。此清单嵌入 Go 程序，修改后需重新构建后端；静态资源也需随构建部署。
4. 部署后在后台选择套装并保存，开启自定义鼠标，检查普通、链接、文本输入等指针状态。前台使用动画，后台使用静态帧；触屏设备不依赖此功能。

可以自行开发或借助 AI 完成。若希望普通站长直接上传 ZIP 创建套装，需要另做资源校验、上传、清单管理和预览等功能。

## 可选工具与需开发的集成

| 需求 | 当前提供的能力 | 还需什么 |
| --- | --- | --- |
| 私信填入助手 | 油猴／浏览器扩展模板，辅助打开编辑器并填入当前通知 | 修改本站域名白名单，必要时设置扩展 ID，重新打包／部署；见[助手文档](../scripts/whisper-helper/README.md)。网站直接发送队列无需安装助手 |
| 自动采集动态和话题中的歌切／画廊投稿 | 后台手动添加、上传和审核 | 通用定时任务、来源配置、去重、审核和风控适配尚未实现 |
| 自动查询快递轨迹／签收状态 | 寄送记录、快递公司、运单号、备注与已寄时间 | 当前不调用快递查询 API；需申请第三方服务并开发。页面“刷新”只重新读取本站保存的记录 |
| 电子面单、仓储／ERP 对接 | 地址导出与批量运单录入 | 需接入所使用的服务，当前不自动下单或推送仓库 |
| 跨月特典自动判断、特殊粉丝资格、新平台登录 | 月份／档位／活动名单与现有批次规则 | 超出现有规则的资格计算或身份核验需单独开发 |
| 自定义页面布局、新入口或新模块 | 主题颜色、名称、图标和现有入口配置 | 超出主题字段的结构与业务需要改代码 |
| 多实例高可用 | 单 API 实例部署和持久化数据 | 部分锁、队列和限速仍在进程内；不能仅复制多个容器就宣称支持分布式运行 |

## 测试覆盖的含义

已对程序构建、自动化回归、新安装、网页初始化和原通用版合成 SQLite 数据升级进行验证。B 站、AI 与 OSS 等外部服务使用模拟测试，不代表真实第三方环境均已实测可用；真实 MySQL 服务器部署与升级、任意桌宠模型和自定义鼠标套装也不在这些测试的验收范围内。

发布或升级前，应使用自己的测试账号核对实际要启用的集成；私信先向测试 UID 发送并确认，不直接对正式名单试群发。
