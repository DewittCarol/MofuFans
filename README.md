# MofuFans

**为 VTuber 和粉丝搭建一个自己的小站。**

使用过程中遇到问题，可以到 B 站联系 [@瞳Gachi](https://space.bilibili.com/610009)。

从直播后的提问、歌单与二创展示，到舰礼地址收集和电子礼物发放，MofuFans 把日常互动与粉丝回馈放在同一个网站里。基础业务已实现，部署并完成初始化后即可录入内容和试用，完成公网安全配置后再开放访问；通常不需要为每位主播重新开发。名称、品牌与模块图标、配色、背景可在后台修改，程序和数据由你自己管理。

## 使用范围与适配边界

“部署后可用”指基础业务可以在后台配置和运营，不代表自带主播素材、第三方账号或完整的公网防护。开放公网访问前，请按[上线与日常安全指南](doc/SECURITY-OPERATIONS.md)完成 HTTPS、可信代理、服务器入口和备份等检查；可以把该文档直接交给协助部署的 AI Agents。

### 后台配置即可使用

| 功能 | 部署后需要做什么 |
| --- | --- |
| 网站名称、主播名称、头像、页签图标、五个模块的入口图标 | 在「主题管理」填写或上传图片并保存，无需改源码 |
| 配色、主题预设、背景、表情与备案页脚 | 后台调整；内置通用图标和轴伊 Joi 表情可直接使用，自定义图片由部署者提供 |
| 提问箱、话题、投稿审核与表情互动 | 设置投稿权限和话题后即可接收投稿 |
| 歌单／歌切、作品画廊 | 在后台添加内容、关联链接或审核粉丝投稿，不自动抓取主播动态 |
| 名单、舰礼介绍、地址收集、地址簿与礼物托管 | 导入或录入名单，配置礼物和收集批次后发布；用户注册不自动获得领取资格 |
| 发货安排、地址导出、运单登记与查询 | 后台安排包裹、录入运单；用户查看本站记录的寄送状态、快递公司和运单号 |
| 电子礼物 | 上传自己的文件，设置公开、统一密码或名单独立密码后上架 |
| 粉丝签名注册、密码登录与个人主页 | 不需要申请 B 站开放平台应用；身份核验依赖服务器能够读取 B 站公开签名 |
| 内置应用防护与安全记录 | 默认启用限速、并发控制和临时封禁；站点所有者在「安全」中查看原因、核对客户端 IP、管理封禁 |

### 需准备素材、账号或部署配置，无需开发基础业务

| 功能 | 配置入口与限制 |
| --- | --- |
| B 站上舰记录导入、站内私信发送队列 | 主播扫码登录自己的 B 站账号，填写私信测试 UID 并确认测试；受账号权限、接口可用性和 B 站风控影响 |
| AI 辅助审核 | 在「系统设置」配置自己的服务、模型与 API Key；默认关闭，不影响人工审核 |
| 阿里云 OSS | 自行创建私有 Bucket 和访问凭据，再在「部署与集成」配置；也可一直使用默认本地存储 |
| 标准 VRM 桌宠 | **有模型地址、名称和显示开关，没有模型上传入口或动作编辑器。** 自行准备获授权的 VRM，放到浏览器可访问的站内静态地址或支持跨域读取的 HTTPS 地址，再在「主题管理」填写。兼容模型可用现有动作运行；并非任意模型都能直接适配 |
| 域名、HTTPS、真实客户端 IP 与备份 | 由部署者配置服务器／反向代理。应用已有默认访问预算，需要时可在私有部署配置调整，参阅[部署指南](doc/DEPLOYMENT.md)和[安全部署](doc/SECURITY.md) |

### 需要修改源码、资源清单或单独开发

| 功能 | 当前边界 |
| --- | --- |
| 自定义鼠标图标／动画套装 | **没有素材上传和套装创建入口，发行版只附系统指针。** 后台只能启停并选择已安装套装。新增套装需准备精灵图及 manifest、登记 `internal/appearance/cursor-themes.json`，重新构建部署 |
| 专属桌宠动作、服装切换、模型骨骼／表情修复、2D／Live2D 桌宠 | 不属于现有地址配置能力，需制作素材并适配或开发；没有可视化编辑器 |
| 私信填入助手 | 可选模板，需按自己的域名修改白名单并重新打包／部署；扩展方式还需配置扩展 ID。网站内的私信发送队列不依赖此工具，详见[助手说明](scripts/whisper-helper/README.md) |
| 自动抓取动态／话题中的歌切和画廊投稿 | 没有可直接配置的通用采集任务；当前通过后台维护内容，自动采集需另行实现 |
| 快递轨迹、电子面单或仓储系统对接 | 当前没有快递服务商 API 集成，不自动查询揽收、运输和签收轨迹；需申请服务并开发对接 |
| 特殊领取条件和新业务规则 | 如跨月额外特典自动判定、新平台登录、新模块或特殊页面布局，需按需求开发 |

上述开发项可以自行实现，也可以借助 AI 修改代码；它们不属于后台已有的上传或配置功能。详细入口、资源准备和验收范围见[功能与适配说明](doc/FEATURES.md)。

### 公网安全状态

默认启用按接口类型划分的 IP／全局访问预算、验证并发限制、IP及账号／领取目标的失败冷却、临时封禁和有界安全记录。封禁及必要失败状态保存在本机持久化目录，重启后继续生效；站点所有者可以在后台「安全」查看、添加或解除封禁，误封时还有停服本地恢复命令，无需安装 Fail2ban 才能获得基础应用保护。

管理接口鉴权、资源编号校验、bcrypt 存储、改密撤销旧会话和独立密钥继续保留。新管理员密码至少15个字符；账号修改和手动封禁需近期密码验证。实时连接增加来源、连接数、消息和广播限制，上传有大小、并发与读取进度限制。随附 Nginx 模板另提供粗粒度 API 总量限制和安全响应头。阈值、覆盖范围、记录期限和恢复操作见[安全部署](doc/SECURITY.md)。

对外开放前仍应配置 HTTPS、可信代理和备份。应用限速无法保护 SSH 或代替网络层的带宽防护，已有 Fail2ban 建议保留。当前未提供 TOTP／Passkey 或设备会话清单；测试与依赖扫描通过也不等于完整安全保证。

## 功能介绍

### 提问箱与粉丝互动

- **接收文字和图片投稿**：粉丝可以按话题投递问题、留言或分享图片。支持匿名投稿，也支持完成 B 站验证并登录后，以自己的身份投稿；具体开放方式由站点设置决定。
- **整理和展示投稿**：后台可以搜索、筛选投稿，调整所属话题，并决定是否公开、隐藏或归档。喜欢的投稿还可以标记为“彩虹屁”，在独立页面集中展示。
- **用表情参与互动**：投稿时可以在正文中插入表情，浏览时也可以给卡片贴表情回应。内置 JoiAsk 原版轴伊 Joi 动态表情与动画贴表情，站长可以继续添加自己的素材。

### 歌单与作品画廊

- **维护主播歌单**：记录歌名、歌手和分类标签，标记唱过的歌曲，并关联 B 站演唱视频。观众可以搜索歌名或歌手，也可以按标签筛选。
- **集中展示作品**：画廊分别展示主播作品和粉丝投稿，支持一份作品包含多张图片，并保留作者署名与作品说明。
- **审核粉丝投稿**：粉丝可以向画廊提交作品，由后台审核后公开展示，方便整理二创、贺图和其他投稿。

### 舰礼展示与发货管理

- **介绍每期回馈内容**：按月份整理舰长、提督、总督等档位的礼物，也可以展示活动或抽奖礼物。礼物卡片的图片素材可以重复使用。
- **按领取范围收集地址**：创建地址收集批次，选择对应月份、档位或活动名单。观众使用 UID 和领取验证码登记地址；同一批次中符合多份礼物资格的人，只需填写一次地址。
- **按实际准备情况安排发货**：地址收集与发货安排分开管理。可以把同一人的多份礼物合并到一个包裹，也可以先寄准备好的部分，剩余礼物之后另行安排。
- **记录包裹与运单**：后台可导出收件地址、登记快递公司和运单号，并批量录入运单。观众可以回到地址收集入口查看寄送状态、快递公司和运单号；当前不自动查询快递运输轨迹。
- **管理常用地址与地址簿**：每位用户可以保存多条地址，但只能设一个常用地址。用户授权后，有领取资格的新批次可自动填写；主播经本人确认也可标记礼物托管。停止自动填写后，后台会标出相关变化，批次备注不会随地址沿用。
- **筛选发货异常**：快速找到缺少地址、地址内容变更或自动填写授权变更的记录。导出只生成发货清单，暂存运单也不会标记为已寄出。

### 粉丝账户与个人主页

- **主动验证 B 站身份**：首次注册时，把本站生成的短验证文字临时填入 B 站个人签名。服务器核对成功后即可设置密码，后续直接用 UID 和密码登录；忘记密码时可再次验证签名。
- **保留注册进度**：关闭弹窗后可在同一浏览器恢复尚未过期的验证流程，点击遮罩不会误关注册弹窗。
- **集中管理领取与物流**：登录后可查看本人的开放收集批次、地址簿和寄送进度。登录时刷新昵称头像，后台名单则使用七天缓存，避免反复查询。

### 共享名单与领取资格

- **统一维护月度和活动名单**：支持大航海月度名单与活动／抽奖名单，可导入 CSV、TXT，或粘贴从表格复制的内容；导入前先预览核对。同一 UID 在一个月内的不同上舰档位可以分别记录。
- **让多项回馈复用同一份名单**：地址收集和电子礼物都可以关联已有名单。添加成员、修改昵称或调整档位后，关联结果会自动更新，减少反复导入和维护多份表格的工作。
- **区分名单成员与单份礼物资格**：可以从名单中排除某条记录，也可以只取消某人对某份电子礼物的领取资格。后一种操作不会影响原名单、实体舰礼或其他电子礼物。

### 电子礼物发放

- **把文件作为礼物发布**：创建礼物介绍和领取说明，上传图片、音频、视频或压缩包。内容可以先存为草稿，准备好后再上架，观众在网站中查看和下载。
- **选择合适的领取方式**：支持无需密码的公开领取、所有人使用同一个密码，以及关联名单后为每位领取人生成独立密码。独立密码模式下，同一 UID 即使出现在多张关联名单中，也只分配一份密码。
- **管理后续领取权限**：可以重置密码、取消或恢复某人的领取资格，也可以将整份礼物下架，暂停继续领取。
- **上传较大的附件**：支持一次选择多个文件，大文件分片上传，并显示当前文件和进度。尚未完成的文件不会提前出现在领取页面。

### B 站名单导入与私信通知

- **扫码导入上舰记录**：用主播账号扫码登录后，可以获取并预览指定月份的购买、续费记录，再确认导入名单。也可以按 UID 同步成员的昵称和头像。
- **发送地址收集和礼物领取通知**：根据名单准备每个人的通知内容，先预览，再向自己配置的测试账号发送示例消息。确认收件内容无误后，才启动正式发送队列。
- **查看和控制发送队列**：可以选择 5–300 秒的预设发送间隔，查看各账号的队列和逐条结果，暂停或取消发送。单次失败会保留记录并继续下一人，连续错误或平台明确限流时冷却；结果不明的消息需要核对后再重试。
- **保留手动发送方式**：可以复制通知后前往 B 站发送，也可以安装私信填入助手，帮助打开对话并填写内容。

### 主题、表情与站点外观

- **设置自己的站点形象**：在后台修改站点名称、主播名称和图标，调整前后台配色、背景及导航中的模块入口。自定义鼠标需另行制作和安装，后台没有素材上传入口。
- **管理投稿表情合集**：可以新建合集、批量上传图片、拖动排序、改名或删除；互动表情还可以直接添加原生 Emoji。删除表情或合集后，历史投稿中的表情仍能显示，已删除的内置合集不会在重启后重新出现。
- **配置网站页脚**：直接填写 ICP／公安备案号、公安备案查询链接和图标，即可在前台页面底部显示，无需修改代码。未填写的项目隐藏，切换主题预设不会覆盖备案信息。

### 可选的 AI 辅助审核

- **连接自己选择的 AI 服务**：支持 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages 协议。填写服务的 Base URL 与 API Key 后，可以获取模型列表，也可以直接指定自定义模型 ID。
- **调整审核标准和模型参数**：站点所有者可以设置低质量内容的判定标准，按模型支持情况选择思考等级、思考预算和输出 Token 上限，并在保存前测试连接与模型。
- **辅助人工整理投稿**：AI 默认关闭。开启后会为新投稿提供低质量标记，供后台筛选，不会自动删除内容；服务不可用时，投稿仍会保留供人工处理。发送内容及密钥管理方式见 [AI 配置指南](doc/AI.md)。

### 部署与后台配置

- **先启动，再完成网页初始化**：首次进入后台时，通过一次性安装码确认站点归属，创建管理员并填写站点信息。默认使用 SQLite 和本地文件存储，无需先准备外部服务或手动生成密钥。
- **按需接入外部服务**：运行后可在后台配置 OSS、私信测试 UID、HTTPS Cookie 和 AI。MySQL、监听端口等高级选项仍可通过部署配置设置。
- **选择文件存储位置**：支持服务器本地存储和阿里云私有 OSS Bucket，并提供后台连接检查。受限附件仍由应用核对访问权限后提供，数据库、密钥和站点数据由部署者自行保存与备份。
- **选择适合自己的部署方式**：提供 Docker Compose、便捷启动脚本、Linux 源码编译，以及自行打包上传的部署方式。详细步骤见下方快速开始及[部署指南](doc/DEPLOYMENT.md)。

## 快速开始

**先试用，再开放。** 不熟悉服务器配置时，先仅在本机或自己可访问的环境运行。交给 AI 部署时，要求它先读 [AGENTS.md](AGENTS.md) 和[安全指南](doc/SECURITY-OPERATIONS.md)，逐项报告验收结果；应用内已有防护，服务器和网络仍需配置。

获取本仓库源码后，在项目根目录选择以下方式部署。当前尚未发布对应的预编译下载包，请从源码构建或自行打包部署。

### 选择部署方式

| 方式 | 适合谁 | 需要什么 |
| --- | --- | --- |
| [便捷启动](#便捷启动) | 希望检查环境后直接启动 | Docker、Compose、Python 3 |
| [Docker Compose](doc/DEPLOYMENT.md#docker-compose) | 自己管理容器，或使用服务器面板／NAS | Docker、Compose |
| [Linux 源码部署](doc/DEPLOYMENT.md#linux-源码部署) | 不使用 Docker，自己管理进程和反向代理 | Go 1.26.11+、Node.js 22.14+、C 编译器、Python 3、Nginx |
| [构建包部署](doc/DEPLOYMENT.md#构建包部署) | 在一台机器编译，上传到服务器运行 | 运行端只需 Nginx 和系统运行库 |

### 便捷启动

安装好 [Docker](https://docs.docker.com/get-started/get-docker/)（含 Compose）和 Python 3 后：

```bash
python3 scripts/deploy.py
```

Windows 使用 `python scripts/deploy.py`。脚本检查 Docker，然后从源码构建并启动容器。**无需先编辑配置文件**，管理员账号和站点信息在网页引导中设置。

启动后打开：

- 前台：<http://localhost:8088/>
- 后台：<http://localhost:8088/admin/>

服务默认监听本机。部署到公网时，按[域名与 HTTPS](doc/DEPLOYMENT.md#域名与-https)和[安全部署](doc/SECURITY.md)配置反向代理和可信代理，并按需调整默认访问限速。

也可以只用 Docker Compose 启动，无需 Python：

```bash
docker compose up -d --build
docker compose logs --tail=100 mofufans
```

### 不用 Docker

在 Linux 或 WSL 中安装构建依赖，然后执行：

```bash
python3 scripts/build-release.py
```

脚本编译 Go 后端、构建两端静态页面，并生成 `dist/mofufans/` 部署目录。之后使用目录中的 Nginx 和 systemd 模板运行服务，完整命令见 [Linux 源码部署](doc/DEPLOYMENT.md#linux-源码部署)。构建包可以复制到兼容的服务器，运行时无需 Node.js 或 Go；启动后同样在网页完成初始化。

## 第一次使用

1. 打开 `/admin/`，首次启动会自动进入配置引导。从服务日志复制一次性安装码，确认站点归属。
2. 创建管理员账号，填写站点名和主播名称。保留默认本地存储即可开始使用；OSS 和私信测试 UID 可以稍后补填。
3. 登录后台，在「主题管理」调整图标、配色、导航、背景、表情与页脚备案，在「系统设置」配置投稿权限和外部服务。
4. 添加歌单、作品或礼物。舰礼和电子礼物页面均附有使用教程。
5. 需要 B 站功能时再扫码登录；发送私信前，先在「系统设置 → 部署与集成」填写自己的测试 UID，再到私信页面发送示例消息并确认收件无误。

默认使用 SQLite 和本地文件，独立密钥自动生成并保存在 `data/`。OSS、私信测试 UID、HTTPS Cookie 及可选的 AI 辅助审核均可在后台配置；MySQL、端口等高级选项仍可通过部署配置提供。参阅[配置参考](doc/CONFIGURATION.md)。

## 后台配置

### AI 辅助审核

AI 默认关闭，不影响站点正常使用。启用时，以站点所有者账号进入「系统设置 → AI 辅助审核」：

1. 选择 **OpenAI Chat Completions、OpenAI Responses 或 Anthropic Messages**，填写服务的 Base URL 和 API Key。可连接对应协议的第三方兼容服务；Base URL 不要带 `/chat/completions`、`/responses` 或 `/messages` 请求路径。
2. 点击「获取模型」后选择模型，或直接填写自定义模型 ID。服务不提供模型列表时也可以手动配置。
3. 填写审核标准，按模型支持情况选择思考等级、输出 Token 上限；Anthropic 还可配置思考模式和预算。不确定时保留服务默认。
4. 点击「测试连接与模型」，通过后开启审核并保存。获取模型和测试不会自动保存配置；保存后对新投稿生效，无需重启。

AI 为投稿提供低质量标记和简短原因，供后台复核，**不会自动删除投稿**。默认仅审核文字；启用图片审核后，会将受大小和数量限制的附图发送给所选服务。审核失败不会丢弃投稿。API Key 在服务端加密保存，后台不回显。数据范围和配置步骤见 [AI 配置指南](doc/AI.md)。

### 主题、表情与页脚

「主题管理」集中管理站点及主播名称、图标、配色、导航、背景、表情素材及桌宠地址／显示开关。投稿权限、鼠标已安装套装选择、外部服务和部署集成则在「系统设置」。

- **表情素材**：内置 JoiAsk 原版轴伊动态投稿表情与动画贴表情；可新建合集、批量上传、拖动排序、改名，以及删除单个表情或整套合集。删除合集会移除其中的可选表情，历史投稿仍正常显示，重启也不会重新生成已删除的内置合集。
- **页脚备案**：填写 ICP／公安备案号、公安备案查询链接及图标，即可在前台页面底部显示；未填写的项目隐藏。备案配置独立保存，切换主题预设不会覆盖。详见[页脚备案配置](doc/CONFIGURATION.md#页脚备案信息)。
- **桌宠模型**：在「主题管理」填写 VRM 地址、名称和显示开关，在「系统设置」选择默认展开状态。没有模型上传、制作或动作编辑入口；仓库不附带角色模型，需自行托管获授权的兼容 VRM。手机端不加载桌宠；特殊模型和动作需开发适配。
- **鼠标套装**：在「系统设置」选择已安装套装，发行版仅含系统指针；主题里的自定义鼠标开关不会自动生成图标或增加套装。新增素材和套装的方式见[适配说明](doc/FEATURES.md#自定义鼠标)。

### 存储与可选集成

在「系统设置 → 部署与集成」中，可以配置本地／阿里云 OSS 存储、自己的 B 站私信测试 UID 和 HTTPS Cookie。默认本地存储即可运行，外部服务可以后续按需接入。

OSS 支持后台填写凭据和检查连接，使用私有 Bucket；受限附件继续由应用检查访问权限。已有站点切换存储时，需先停止写入、备份并迁移旧文件，核对后保存设置并重启 API，系统不会自动复制旧文件。数据库、实例密钥及临时上传仍需持久化，操作步骤见 [OSS 配置与迁移](doc/CONFIGURATION.md#阿里云-oss)。

## 常见问题

**必须购买 OSS 吗？** 不需要，默认文件存储在本地 `data/`。使用 OSS 时，数据库和未完成上传的临时文件仍需持久化。

**有默认管理员账号吗？** 没有。首次网页引导中自行设置账号密码；只有持有服务端安装码的人可以初始化，完成后安装入口关闭。

**一定要先配置 OSS、B 站或 AI 服务吗？** 不需要。它们都是可选集成，可以先完成基础配置，再进入后台补充。部署配置文件和环境变量也继续可用，适合自动化部署。

**能只部署到 GitHub Pages 或其他静态托管吗？** 完整站点需要运行 Go API 和持久化数据库。静态页面由 Nginx 提供，前后台与 API 建议使用同一个域名。

**私信会直接群发吗？** 需要先预览、向自己配置的测试账号发送并确认，再启动队列。当前登录账号会自动从收件名单中排除。失败与结果不明的消息会显著标记，重试前请核对 B 站，避免重复发送；平台状态可能影响导入和发送。
